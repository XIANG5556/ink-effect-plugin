# ink特效插件

## 直接下载

[点击下载 ink特效插件 v1.0.0](https://github.com/XIANG5556/ink-effect-extension/raw/refs/heads/main/dist/ink-effect-extension-v1.0.0.zip)

下载后先解压，再打开 Edge 或 Chrome 的扩展管理页面，开启“开发人员模式”，点击“加载已解压的扩展程序”，选择解压后的文件夹。

这是一个独立的 Chrome / Edge Manifest V3 浏览器插件。网页内容、网页标题、搜索地址、搜索框或评论输入框里出现独立英文单词 `ink` 时，会在页面中央弹出亮紫色立体墨汁特效，并同步播放短促的喷墨音效。

## 安装

1. 解压插件压缩包。
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展程序”。
5. 选择解压后的“ink特效插件”文件夹。
6. 刷新已经打开的网页。

## 效果与触发

- 只识别独立英文单词 `ink`，大小写均可。
- `think`、`inking`、`pink` 等其他英文单词不会误触发。
- 输入完成后无需按回车，墨汁会立刻弹出。
- 墨汁出现时会播放约 0.86 秒的“喷射＋落墨”音效。
- 动画约 4.2 秒：快速弹出回弹、轻微晃动、最后放大渐隐。
- 支持普通网页、网页搜索框、抖音网页版搜索框和评论区。
- 浏览器设置页、扩展商店和新标签页等受保护页面不允许插件注入，这是浏览器限制。
